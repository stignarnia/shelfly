Shelfly 4.0.1

• Fixed the label and outline of text fields in dialogs (API keys, WebDAV, backup retention) turning near-black and unreadable once the field was focused.
• Dropped the crown icon from the Theme setting. It marked a Showly premium feature that no longer exists in this fork.
• Fixed IMDb, Metascore and Rotten Tomatoes ratings never loading. Details were served from a cache entry that carried no IMDb id, so there was nothing to look up, and OMDb was queried on a host that only accepts paid keys.
• Fixed the movie Discover page failing to load entirely.
• Ratings that cannot be found now show as absent instead of spinning forever.
• With no OMDb key set, IMDb, Metascore and Rotten Tomatoes now show a cross you can tap for an explanation, instead of sitting there empty.
• Pull to refresh on Discover now opens a slot above the list instead of floating over it, so the indicator never overlaps the filters or the posters, and it carries the TMDB mark.
• Removed the ten second cooldown that silently ignored a second pull to refresh.
• Discover now filters by streaming service, on both shows and movies. The chips are the services TMDB lists for the country set in Settings, so the list matches your region rather than a fixed set of American networks, and the filter reaches TMDB instead of being dropped.
• The Discover genre filter now also applies to the anticipated titles mixed into the trending feed, and to the anticipated feed itself, which both ignored it before.
• The network filter in My Shows, Watchlist and Hidden now offers the broadcasters your collection actually holds, instead of a fixed list that omitted most non-American ones. Selections made against the old list are cleared.
• Several filters accept more than one selection now instead of crashing on the second.
