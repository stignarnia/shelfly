<p><b>NOTĂ:</b> Această aplicație nu este destinată vizionării de filme sau seriale. În acest scop, folosiți aplicațiile oficiale de streaming.</p><p><b>Shelfly</b> este un instrument de urmărire a <b>Serialelor și Filmelor</b> care se sincronizează cu infrastructura proprie.</p><p>În loc să vă stocheze istoricul pe un cont terț cu API plătit, Shelfly face backup pe <b>propriul dvs. server WebDAV</b> (Nextcloud, NAS etc.) conform programului ales. Fără conturi, fără abonamente, fără intermediari. Catalogul provine de la TMDB folosind o cheie API gratuită furnizată de dvs.</p><ul><li><b>Progres:</b> Urmăriți serialele și filmele vizionate. Nu ratați niciun episod.</li><li><b>Descoperire:</b> Explorați titluri populare și așteptate.</li><li><b>Colecție:</b> Gestionați ce vizionați și vedeți statistici.</li><li><b>Liste personalizate:</b> Creați propriile liste.</li><li><b>Backup WebDAV:</b> Salvați automat colecția pe serverul dvs.</li><li><b>Notificări și Widget-uri:</b> Primiți notificări și folosiți widget-uri pe ecranul principal.</li></ul><p>Shelfly acceptă mai multe limbi.</p><p>Shelfly este un fork al Showly, creat de Michał Drabik și menținut de Trakt, GPL-3.0.</p><p>Acest produs folosește API-ul TMDB, dar nu este aprobat sau certificat de TMDB.</p>
